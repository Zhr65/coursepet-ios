# 艾宾浩斯复习计划（间隔重复法）

当主人要复习/备考某科目时，按以下流程执行：

1. 先调 get_today_schedule 和 get_pending_homeworks 了解近期日程与负担，避开忙碌日。
2. 从考试日倒推，用 create_study_plan 拆成逐日任务，间隔节奏固定为：
   - 每个新内容学习日之后的第 1、3、7、15 天各安排一次复习
   - 每天最多 2 项任务；考前 3 天只做模拟与错题，不加新内容
   - 任务要具体可验证（如"重做第三章泰勒公式错题"，而不是"复习第三章"）
3. 创建后调 check_study_plan 确认计划已落库，报出前 3 天的任务。
4. 收尾问一句：要不要每天固定时间提醒复习进度（同意就 create_task 建每日提醒）。
